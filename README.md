# CareerCV Builder

A responsive, browser-based CV and resume generator built with **HTML, CSS and Vanilla JavaScript**.

CareerCV Builder is designed for students, graduates, job seekers, career changers, freelancers and working professionals. Users can enter their information, preview a professionally formatted CV in real time, save work locally in the browser, customise the accent colour, switch between light and dark mode, upload a profile photo, and print/save the CV as a PDF.

## Features

- Personal information and contact details
- Professional summary
- Education history
- Work experience
- Skills
- Projects
- Certifications
- References / referees
- Profile photo upload
- Live CV preview
- Accent colour selection
- Light / dark mode
- Local browser storage
- Responsive desktop, tablet and mobile interface
- Print-to-PDF using the browser print dialog
- No server or database required

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
- Browser Print API

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Fill in your information.
4. Select **Print / PDF** or **Download PDF**.
5. In the browser print dialog, choose **Save as PDF**.

## GitHub Pages

Because this is a static web application, it can be hosted with GitHub Pages.

Go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Expected project URL:

`https://tsamiyaonline.github.io/career-cv-builder/`

## Privacy

CV data is stored locally in the user's browser using Local Storage. The project does not require a backend server. Users should avoid entering highly sensitive information on shared/public devices.
